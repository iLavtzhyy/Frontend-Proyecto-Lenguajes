# VetSphere Frontend

Frontend Angular 17+ con Tailwind CSS y animaciones para abrir en Visual Studio Code.

## Ejecutar

1. Abrir la carpeta `frontend`.
2. Ejecutar `npm install`.
3. Ejecutar `npm start`.
4. Abrir `http://localhost:4200`.

## Pantallas incluidas

- Login.
- Registro.
- Verificacion de 2 pasos por correo.
- Dashboard.
- Mascotas con perfil, timeline clinico, drag and drop y descargas.
- Veterinarios con foto e informacion profesional.
- Recepcion.
- Farmacia y stock critico.
- Administracion.
- Reportes PDF y Excel.
